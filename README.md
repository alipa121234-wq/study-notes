# 讀書筆記 × 考題產生器

考試用的筆記工具：貼截圖、在截圖上畫記、用說的寫字、螢光筆標重點，
然後把標記過的重點**自動變成考題**，用間隔複習法幫你記起來。

---

## 怎麼打開

雙擊 **`啟動筆記工具.bat`**，瀏覽器會自動開啟。
要結束時，關掉那個黑色視窗就好。

> **為什麼要用這個 .bat，不能直接點 index.html？**
> 語音辨識（麥克風）只在 `http://localhost` 或 https 網址下才會運作，
> 直接用 `file://` 開啟會沒有語音功能。
>
> 建議用 **Chrome 或 Edge**（語音輸入只支援這兩個）。
> 第一次按語音時瀏覽器會問麥克風權限，選「允許」。

資料存在這台電腦的瀏覽器裡（IndexedDB）。**請定期用左下角「備份/還原」匯出備份檔。**

**重複雙擊沒關係** —— 如果已經有一份在跑，它只會再開一個瀏覽器分頁，不會重複啟動。

3. iPad 開 `http://<電腦名稱>.local:8760`

## 資料夾分類

左側「＋ 資料夾」建立分類（例如：生物、化學、國文），筆記歸在資料夾底下。

- **搬移筆記**：直接把筆記**拖到資料夾上**，或按筆記右邊的 `⋯` → 選資料夾
- **收合／展開**：點資料夾名稱
- **資料夾選單** `⋯`：在這裡新增筆記 / **🧠 複習這個資料夾** / 重新命名 / 換顏色 / 刪除
- **只複習一科**：資料夾選單的「複習這個資料夾」會把該科所有筆記的題目一起出，考前很好用
- 資料夾右邊的紅色數字 = 這個資料夾**還有幾題到期要複習**
- 刪除資料夾**不會刪筆記**，裡面的筆記會移到「未分類」
- 按 `＋ 新筆記` 會建在**目前選到的資料夾**裡
- 搜尋時會改成平面清單，每筆下面標示它屬於哪個資料夾

## 五大功能

### 1. 貼截圖 + 在截圖上標記
- 在頁面上直接 **Ctrl+V** 貼上截圖，或把圖片檔拖進來，或按「＋圖片」。
- 按 `B`（畫筆）或 `H`（螢光筆）就能直接畫在圖上。
- 圖片下方的「圖說」欄會被拿去出考題（寫成問句就變成看圖題）。

**圖片轉文字（OCR）**

滑鼠移到圖片上 → 右上角 **🔤** → 選「中文為主」或「只有英文」，
辨識出來的文字會自動變成一個**新的文字區塊**插在圖片下面，
接著就能用螢光筆標記、拿去出考題。

> ⚠️ **一定要先校對錯字再標記。** OCR 不是百分之百準確，
> 常見的錯誤是形近字（護→訁隻、警察→警窣）和英文大小寫。

- 用的是 **Windows 內建的 OCR**，完全離線、不用安裝任何東西、不會把圖片傳出去。
- 小圖會自動放大兩倍再辨識，準確度差很多。
- 中文字之間多出來的空白會自動接回去。
- 一張圖大約 1 秒。
- 只有**圖片**區塊有這個按鈕；畫圖區沒有（內建 OCR 認不了手寫字）。

**選哪個語言？**

| 圖片內容 | 選 |
|---|---|
| 課本、講義（中文為主，夾雜英文） | 中文為主 |
| **純英文**的單字表、填空題講義 | **只有英文** |

英文內容選錯語言會明顯變差 —— 中文引擎會把 `winner` 認成 `vinner`、`police` 認成 `POlice`。

**填空題講義**

那種「句子中間一條長底線」的講義可以直接丟進來。
底線會被找出來變成 `______`，被底線切開的左右兩段文字也會接回同一行：

```
1. Jane is always a winner in writing contests.
   She wants to be a ______ in the future.
2. Wayne and Ted were school ______ fifteen years ago.
4. Nick's rice is very popular in town, he is a ______
```

**接著在筆記裡對 `______` 點兩下**，會跳出來讓你填答案。填完自動換成答案並上好黃色螢光筆，
一步完成，不用再自己選字按 `Alt+1`。

> ⚠️ **不要直接把 `______` 標成螢光筆。**
> 底線只是「這裡有空格」的記號，標它的話答案就會變成底線本身，複習時永遠答不對。
> 真的標到了也沒關係，產生考題時會擋下來並提醒你。

> 目前假設是**單欄**排版。兩欄對照的頁面（例如左中右英）會被接成同一行，
> 這種請分兩次截圖，一欄一張。

**已知認不出來的東西**

- 中文的 **一、二、三** 常常會整個消失（它們就只是幾條橫線，OCR 分不出來）
- 孤零零的小標點（底線後面那個句點、分號）容易被漏掉
- 形近字：護→訁隻、警察→警窣、writing→Wliting

在 iPad / iPhone 上不需要這個功能 —— iOS 內建的**「實況文字」**更準：
在圖片上長按 → 選取文字 → 拷貝 → 貼進筆記就好。

### 2. 語音寫字
- 按工具列 🎙️ 或 **F2** 開始／停止。
- 文字會即時插入游標所在的位置。
- 語音打出來的字就是一般文字，一樣可以選取後上色、上螢光筆。

**標點符號**（語音列上的「標點」下拉選單，三選一）：

| 模式 | 行為 |
|---|---|
| **自動斷句**（預設） | 依你講話的**停頓長度**自動補標點，同時也認說出來的標點 |
| 只認說出來的 | 停頓不加，只有你說「逗號／句號」時才加 |
| 不加標點 | 完全照原樣輸出 |

自動斷句的規則：

- 停超過約 **1.3 秒** → 上一句補 **。**
- 停約 **0.5～1.3 秒** → 補 **，**
- 幾乎沒停 → 不加（判定成同一句被切成兩段）
- 上一句以 **嗎／呢／吧／嘛** 結尾 → 補 **？**
- 下一句以 **然後／所以／但是／因為…** 開頭 → 句號自動降級成逗號
- 停止錄音時，最後一句自動補上句號

實際口述的效果（四段話中間有長短不一的停頓）：

> 光合作用發生在葉綠體。分為光反應與碳反應，光反應在類囊體膜上進行，然後碳反應在基質中進行。

不管哪個模式，說 **逗號、句號、問號、驚嘆號、頓號、冒號、分號、換行**
都會變成對應的標點（「不加標點」模式除外）。

> 💡 標點對出考題很重要 —— 出題是用句號、問號來切句子的。
> 沒有標點的話，整段會被當成一句，挖空題會變得又臭又長。

### 3. 筆與筆記

三種區塊，用途不一樣：

| 區塊 | 用途 | 會變成文字嗎 |
|---|---|---|
| **＋文字** | 打字、語音、**觸控筆寫字**、螢光筆標記出題 | ✅ 會（能出考題）|
| **＋圖片** | 貼截圖，可以在上面畫記 | ❌ 只有下面的「圖說」算文字 |
| **＋畫圖區** | 空白畫布，給**算式、圖解、流程圖** | ❌ 保留筆跡原貌 |

**大多數時候用「＋文字」就好。** 它同時有文字層和筆跡層 ——
可以打字、可以用觸控筆寫（會轉成文字）、也可以在寫好的字上圈重點畫箭頭。

「＋畫圖區」只在**打不出來、也不需要出成考題**的東西才需要：數學算式、化學結構、幾何圖。

**用觸控筆在文字段落上寫字時**，按該區塊右上角的 **📐** 可以：
- **顯示格線** —— 寫字時比較好對齊
- **加高** —— 空的段落只有一行高，加高才有地方下筆（右下角還能再拖曳微調）

- 每個區塊右上角有 ↑ ↓ 🧹（清這塊的筆跡） 🗑（刪除）。

**畫錯了怎麼辦**（三種層級）：

| 想做的事 | 怎麼做 |
|---|---|
| 退掉剛剛那一筆 | 工具列 **↶** 或 `Ctrl+Z`（可以一直往回退） |
| 退太多想拿回來 | 工具列 **↷** 或 `Ctrl+Shift+Z` |
| 擦掉零散幾筆 | `E` 橡皮擦（碰到哪一筆就整筆消失），或按住 `X` 暫時用 |
| 這張圖／這塊全部重來 | 滑鼠移到區塊上 → 右上角 **🧹**（一樣可以 `Ctrl+Z` 還原）|

> `Ctrl+Z` 在**畫筆模式下一定是復原筆跡**，就算游標還停在文字區也一樣；
> 回到選取模式（`V`）時，`Ctrl+Z` 才會變回一般的文字復原。

### 4. 換色／換粗細的四種快捷方式

| 想做的事 | 怎麼按 |
|---|---|
| 換顏色 | `1` `2` `3` `4` `5` |
| 換粗細 | `[` 變細 · `]` 變粗 · `Ctrl+滾輪` 無段微調 |
| **在兩支筆之間來回**（例如黑筆↔紅筆） | `Tab` |
| **輪盤色盤**（手不用離開紙面） | 按住 `空白鍵`（或**滑鼠右鍵長按**）→ 游標處跳出圓形色盤 → 往方向撇 → 放開 |
| 暫時用橡皮擦 | **按住 `X`**，放開自動回到原本的筆 |
| 切換工具 | `V` 選取／`B` 畫筆／`H` 螢光筆／`E` 橡皮擦 |
| 復原筆跡 | `Ctrl+Z` |

> 單鍵快捷鍵只在「沒有在打字」的時候有效。
> 正在打字時想切工具，加 `Alt`：`Alt+B` / `Alt+H` / `Alt+E` / `Alt+V`。
> 橡皮擦是「整筆刪除」——碰到哪一筆就整筆消失，比慢慢擦快很多。

### 5. 螢光筆標記 → 自動出題

選取文字後按 `Alt` + 數字，**不同顏色 = 不同題型**：

| 按鍵 | 顏色 | 出題方式 |
|---|---|---|
| `Alt+1` | 黃 | **挖空填空**：整句留下來，標記的字變成空格 |
| `Alt+2` | 綠 | **名詞解釋**：「請解釋：○○」，答案是整句 |
| `Alt+3` | 粉 | **易錯重點**：一樣挖空，但複習時會**優先出現** |
| `Alt+4` | 藍 | **整句問答**：標記的整段當答案 |
| `Alt+5` | 紫 | 只是標重點，**不出題** |
| `Alt+Shift+1~5` | — | 改**文字顏色**（不是背景） |
| `Alt+0` | — | 清除選取範圍的標記 |
| `Alt+Q` | — | **手動出題**：選取的文字當答案，自己輸入題目 |

除了螢光筆，系統也會自動抓：
- 寫成「**名詞：解釋**」的句子 → 「什麼是○○？」
- 圖片／畫圖區的**圖說** → 看圖題

**一小題跨兩行時會自動補上文。** 像這樣：

```
1. Jane is always a winner in writing contests.
   She wants to be a 【winner】 in the future.
```

標記在第二行，但光看第二行答不出來。出題時會自動往前接到
該小題的編號（`1.` `2.` `(3)` `（一）` 都算），變成：

> 1. Jane is always a winner in writing contests. She wants to be a ＿＿＿ in the future.

如果標記所在那一行**本身就有編號**，就不會多加上文。

按 **📝 產生考題** 會列出所有自動抓到的題目，可以逐題「不要這題」，
確認後按「加入題庫」。

### 複習（間隔重複）
按 **🧠 複習**（這份筆記）或左下角 **🧠 全部複習**（所有筆記）。

- **自己打答案** → 按 `Enter` 送出，系統會告訴你對不對
- 不會的話直接按 `Enter`，就會顯示答案
- 看到答案後再評分：`1` 不熟 / `2` 普通 / `3` 很熟
- 比對時會忽略大小寫、空白和標點，所以 `officeworker` 和 `Office Worker` 都算對
- 多寫一些鋪陳也算對，只要答案包在裡面（「他是一個 office worker」✓）

**答案是一整段說明時（多半是 AI 出的題）**

字串比對沒辦法判斷一段話對不對 —— 你講的可能完全正確，只是用字跟範例答案不同。
所以這種題目**不會給對錯**，改成把你寫到的字詞**在正確答案上標成黃色**，
你一眼就能看出哪些重點提到了、哪些漏了，再自己評分。

```
你寫：job可數 work不可數

正確答案（黃底為你答到的）：
  ▉job▉ 是「▉可數▉名詞」（Countable），指特定的一份職業…
  ▉work▉ 作為工作時通常是「▉不可數▉名詞」（Uncountable）…
```

這樣就知道核心觀念答對了，只是沒提到英文術語和例子。

> 作答時整個鍵盤都留給你打字 —— 空白鍵、數字鍵都能正常輸入，
> 答案是「office worker」或含數字也沒問題。只有 `Enter` 會送出。
- 答錯 → 今天稍後再出現；答對 → 依 **1 → 3 → 7 → 16 天** 的間隔往後排
- 側欄會顯示每份筆記「還有幾題待複習」

### 想要更難的題目？
在「產生考題」視窗按 **「複製提示給 AI 出更難的題」**，
貼給 Claude／ChatGPT，把它回覆的 JSON 用 **「貼上 AI 題目」** 貼回來就匯入了。

## 檔案結構

```
筆記考題工具/
├─ 啟動筆記工具.bat        ← 平常自己用（只綁本機，最安全）
├─ 啟動筆記工具-iPad.bat   ← 要讓 iPad/iPhone 連進來時用這個
├─ serve.py          本機伺服器（不快取標頭；也代跑 OCR）
├─ ocr.ps1           圖片轉文字，呼叫 Windows 內建的 OCR 引擎
├─ index.html
├─ app.css
└─ js/
   ├─ store.js    資料儲存（IndexedDB）
   ├─ ink.js      筆跡引擎、輪盤色盤
   ├─ editor.js   文字選取標記（螢光筆／字色）
   ├─ voice.js    語音輸入
   ├─ quiz.js     出題規則與複習排程
   └─ app.js      介面組裝
```
